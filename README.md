# Intenta — Intelligent Interactive Design Prototype

**Word count:** 1,004

## Project overview and status

**Intenta** is a React prototype that explores how intelligent interactive techniques can help users express, explore and refine creative intentions across different visual design domains. It supports users in describing initial ideas, comparing design concepts, clarifying preferences, discovering creative inspiration and refining design elements through interactive feedback.

The envisioned full application would integrate AI models to interpret user intentions, generate design concepts and support conversational design refinement. For this assignment, these AI-assisted interactions are **simulated using deterministic rules and predefined design data**, rather than connected AI models. The current prototype demonstrates the core interactions primarily through a business-card design workflow, while the broader system is intended to support different types of visual design.

**Implemented features**

- **Explore Ideas:** Optional prompt assistance; three CSS-rendered design concepts; new design directions and variations; structured **Like / Avoid / Not Sure** feedback; reviewed updates to an **Active Design Brief**; explicit conflict resolution; and design approval.
- **Community Inspiration:** A searchable, filterable gallery of curated artwork; project detail pages; **Saved Inspiration**; confirmed transfer of supported design attributes or reference-only linking; and optional suggestions when repeated uncertainty is detected.
- **Refine Design:** A structured business-card canvas with object selection, numbered pointers and linked instructions; direct editing, movement, duplication, deletion and rotation; Undo/Redo; proposed conversational changes that users preview and accept or reject; and PNG/SVG artwork export.
- **Projects:** A project gallery with resume and deletion controls; browser-local autosave using IndexedDB with a localStorage fallback; and editable `.intenta.json` backup/import.

**Simulations and limitations**

- Prompt interpretation, recommendations, uncertainty detection and conversational refinement use **deterministic rules and predefined design data**. The running prototype does **not** connect to an LLM or generative image API.
- Community artworks are curated local examples, not live user submissions. The editor handles supported business-card objects, not arbitrary images or unrestricted image generation.
- There is no backend, account system, cloud synchronisation or hosted sharing. Browser-local saves may be lost if site data is cleared or storage is unavailable; editable backups can be downloaded separately.
- Optional dark mode was deferred and is not implemented.

## Running and inspecting the prototype

**Running Intenta React prototype:** Node.js and npm (developed using Node.js 24), plus a modern web browser. Download or clone the repository, then run the following commands **from the repository root**:

```bash
cd app
npm install
npm run dev
```

Open the local URL shown by Vite (usually `http://localhost:5173/`) in Google Chrome.

**Suggested walkthrough:**

1. Create a project and submit a business-card request in **Explore Ideas**.
2. Compare the three concepts, optionally review and confirm attribute feedback, then use **Choose Next Step** to explore new directions, generate variations or approve a design.
3. Open **Current Intentions** to inspect the original and active briefs, confirmed preferences and linked artwork references.
4. Visit **Community** to browse and save inspiration, then explicitly review any transfer to a project.
5. Select a concept and open **Refine Design** to edit objects, preview proposed changes and export PNG/SVG artwork.
6. Use **Projects** to resume a design or download/import an editable project backup.

Optional verification commands (run from `app/`):

```bash
npm run lint
npm run build
node --test
npm run preview
```

`npm run preview` serves the production build generated by `npm run build`. Automated tests are located in `app/tests/`.

## AI assistance

**Tool used:** OpenAI ChatGPT, as a development assistant, not a runtime component. It helped compare interaction approaches, draft React/JSX and CSS, propose rule-based logic, troubleshoot integration problems and prepare testing checklists.

I defined the project scope and wireframes, selected the interaction requirements, integrated and adjusted suggested code, and verified behaviour through local tests and manual Chrome checks. For example, I simplified competing exploration actions into **Choose Next Step**, required explicit review before preferences or proposed canvas edits take effect, and refined the composer, panels and sidebar after visual testing. AI-generated suggestions were therefore reviewed and revised rather than adopted without evaluation. Further examples are recorded in the [development log](DEVELOPMENT_LOG.md).
